# DiceTale（骰子物语）

一个轻量级的桌游跑团 Demo 项目，用于展示跑团（TRPG）中的角色卡与骰子判定概念。

## 项目定位

- **名称**：DiceTale / 骰子物语
- **核心意象**：Dice（骰子）+ Tale（故事），代表跑团中“掷骰驱动叙事”的体验。
- **当前阶段**：Demo 骨架，仅作项目展示与命名占位。

## 目录结构

```
DiceTale/
├── index.html      # 项目入口页
├── assets/
│   ├── style.css   # 基础样式
│   └── app.js      # 前端交互脚本
└── README.md       # 项目说明
```

## 本地预览

用浏览器直接打开 `index.html` 即可。
